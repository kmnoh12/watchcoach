# AirPods Max reference photos

Downloaded from Wikimedia Commons (search "AirPods Max"), 1200 px thumbnails, used only as modeling
reference for the silver AirPods Max in `promo/tools/reel_gym.py` (`airpods_max`). Each file keeps its Commons
name with spaces as underscores; see the Commons page of the same name for author and license.
Specs used: 168.6 x 83.4 x 187.3 mm (W x D x H, with cushions), apple.com AirPods Max specs page.
