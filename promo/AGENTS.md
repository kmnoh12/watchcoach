# 워치코치 릴스 렌더 규칙

## 핵심 — 초안에서 렌더 장수부터 계산한다

1. 대본과 장면 초안을 짤 때 컷별 시작·끝, 중요한 동작과 화면이 바뀌는 시점을 24fps 타임라인에 적는다. 한 컷 안에서도 움직임이 달라지면 구간을 나눈다.
2. 아래 표로 구간별 새 이미지 장수와 반복 프레임 수를 계산한다. 24·12·6장/초 구간은 출력 프레임 수를 각각 1·2·4로 나눠 올림한다. 완전 정지 구간은 길이에 관계없이 한 장을 센다. 새 이미지와 반복을 더한 값이 최종 출력 프레임 수와 일치할 때 렌더를 시작한다.

| 장면 | 실제로 렌더할 이미지 | 최종 24fps에서 유지하는 길이 |
| --- | ---: | --- |
| 운동 동작, 빠른 카메라 이동 등 움직임을 자세히 보여줘야 하는 구간 | 초당 24장 | 이미지당 1프레임 |
| AI 로고가 통통 튀거나 늘어나는 동작, 가벼운 몸짓이나 손목 진동 | 초당 12장 | 이미지당 2프레임 |
| 작고 드문 움직임, 정지 포즈에 가까운 구간 | 초당 6장 | 이미지당 4프레임 |
| 정지 포즈, 액자 게스트, 로고 카드 등 렌더 화면이 완전히 고정된 구간 | 구간 전체에 1장 | 구간 끝까지 |

- 구간 시작 프레임부터 필요한 이미지만 렌더하고, 남는 출력 프레임은 직전 이미지를 그대로 반복해 채운다. 최종 MP4는 고정 24fps로 내보내고 프레임 보간은 끈다.
- 컷과 렌더 화면에 보이는 효과가 바뀌는 프레임에서는 새 이미지를 뽑고 반복을 다시 시작한다. 구간 끝에서 마지막 반복을 자른다. TTS와 편집에서 얹는 자막은 출력 타임라인에서 따로 타이밍을 잡는다.
- 출력 후 24fps, 길이, 컷·효과 전환 위치를 확인한다. 실제 렌더 장수와 동일 이미지 반복 구간이 초안의 계산과 일치하는지 확인한다.
