## 문제 진단(합의됨)
지금 결과 화면은 길어서가 아니라 **정보 선택이 잘못**됐다. 개발자용 문구·세션 번호·계산 근거·세트마다 "손목 기반 추정 / 폰 재분석 / 검증 필요" 같은 내부 정보가 10줄 넘게 붙는다. 접기만으로는 해결이 안 되고 내용을 다시 골라야 한다.

## 합의된 방향
- 기본: 시간·세트·볼륨을 짧게 + 운동별로 `20kg × 12회` 같은 실제 수행 기록만.
- 눌렀을 때: 세트별 "일정함 / 후반 빨라짐 / 후반 느려짐", 이 종목 지난번 대비 평균 속도 빠름·느림을 심플한 수치·그래프로. 신호 품질·측정 방식 같은 내부 정보는 노출 금지.
- 공유: 요약형과 상세형 둘 다 + 텍스트 저장(텍스트 저장은 이미 구현됨).
- 앱 문구는 반말 금지, 중립 표현("지난 기록 대비 +1회"). 사용자에게 내부 설명·주의 문구 노출 금지.
- 탭·스와이프만 늘리는 구조는 피한다(StrengthLog 되돌림 사례). 세부 구성은 미정 — 사용자와 상의하며 정한다.
- 비교는 같은 측정 기준끼리만, 이는 앱 내부에서 처리하고 화면에서는 설명하지 않는다.

## 새로 생긴 것(이 화면에 반드시 들어가야 함)
- **"추정" 세트 확인·확정**: 반대손 자동 종료와 수동 운동 세트 타이머(커밋 3ad801ac, 69eca4b2)로, 센서로 안 잰 횟수가 `ESTIMATED`로 기록된다. 지금은 `WorkoutResultScreen`에서 탭해 고치면 `FinishedWorkoutStore.confirmOther`로 확정된다. 새 결과 화면에서도 작고 눈에 띄지 않게 "추정" 표시 + 탭 확정 경로를 유지해야 한다. 추정 세트는 과부하 판단에서 제외된다.
- 폰 운동 중 화면의 완료 칸에 원암 "한쪽 완료" 반투명 체크가 있다(결과 화면과 별개).
