# 운동 결과화면 + 오운완 카메라 공유: 안드로이드 구현 지시서 (2026-11-11)

폰 앱(`phone/`)의 운동 후 결과화면을 확정 시안대로 다시 만들고, 오운완 카메라 공유를 새로 붙여라.
사용자(Kyungmin)는 개발자가 아니다. 시안이 정답이다. 시안과 다르게 "개선"하지 마라.

## 결과화면 (확정)
- 위에서부터: 오운완 카드 → '○○ 완료' 제목 → 큰 숫자 3칸(운동 시간 / 총 볼륨 / 세트) → 민트 비교 띠('지난번보다 N종목 상승', 아래 작은 줄 '유지 · 하락 · 최고 기록') → 종목 카드 목록 → 심박·kcal 한 줄 → 하단 고정 버튼(내보내기 / 확인).
- 종목 카드: 처음엔 접힘. 한 줄에 '종목명', 그 아래 'N세트 · 최고 kg × 회', 오른쪽에 증감('+2회', '유지', '−1회', '+2.5kg'; 상승은 민트). 누르면 펼쳐져서 세트가 **세로로 한 줄씩**: 세트 번호 / 오늘 kg×회 / 지난번 kg×회. 무게는 세트마다 다 적는다. 최고 기록 세트엔 작은 민트 '최고'.
- **절대 금지**: 세트를 가로 칸으로 늘어놓기(넘치면 화면 밖으로 나감). 세트 행을 눌러 횟수 고치는 기능 추가(사용자가 명시적으로 거부함).
- 추정(ESTIMATED) 세트: 데이터 처리와 지금 있는 확정 흐름은 그대로 살려 둬라. 새 화면에서 세트 행 탭 편집을 새로 만들지는 마라.
- 결과화면을 스크롤하면 오운완 카드는 흐려지고 살짝 줄며 사라진다(120dp 동안 opacity 1→0, 아래로 10dp, scale 1→0.96).
- 스크롤해서 카드가 없어졌을 때 카메라를 여는 길: 내보내기 시트 안에 '사진 찍어 공유' 항목을 하나 넣는다.

## 오운완 카드 (확정)
- 카드 = **카메라 화면 9:16 사진 틀의 윗부분을 그대로 잘라 보여주는 창**이다. 위치·크기·곡률이 9:16 틀과 똑같다:
  카드 왼쪽·너비·위쪽 높이 = 카메라 화면의 9:16 틀과 같은 값(시안: 화면 왼쪽 11, 너비 366, 화면 위에서 56). 그래서 카드만 아래 종목 카드들보다 양옆으로 5dp씩 넓다. 실제 기기 폭에서는 카메라 틀 값을 기준으로 카드를 맞춰라.
- 배경 = 실시간 후면 카메라 미리보기에 블러(16dp)와 검정 45% 막. 9:16 틀에 깔리는 것과 같은 그림·같은 배율이어야 한다(흐릴 때 따로 확대하지 마라).
- 곡률: 카드와 카메라 사진 틀(9:16·1:1·3:4 전부)은 **같은 값 22dp 하나**를 쓴다(상수 하나로 묶어라). 카드 안 '카메라 열기' 버튼 곡률 = 22 − 12(버튼과 카드 가장자리 간격) = 10dp.
- 문구: '오운완 사진 남기기' / '거울 앞에서 찍으면 오늘 기록이 같이 들어가요' / 민트 버튼 '카메라 열기'.
- 카메라 권한이 없으면 카드는 블러 사진 대신 어두운 배경으로 보이고, '카메라 열기'를 누를 때 권한을 묻는다.

## 카메라 열기·닫기 연출 (확정)
- '카메라 열기': 카드가 그 자리에서 화면 전체로 펴진다(시안의 clip-path: 카드 사각형에서 전체 화면으로 0.46초, 곡선 cubic-bezier(.2,.8,.2,1)). 펴지는 동안 사진은 같은 장면이 그대로 이어진다(틀이 카드와 겹친 상태에서 시작).
- 블러: 열기 시작 **0.15초 뒤**부터 **0.3초** 동안 블러와 검정 막이 화면 전체에서 동시에 서서히 걷힌다(위에서 아래로 쓸어내리는 방식은 사용자가 거부함). ✕·기록 글씨·하단 바는 0.28초에 나타난다.
- ✕를 누르면 같은 길로 거꾸로: 블러가 다시 덮이고 카드로 접힌다. 열 때와 닫을 때는 항상 9:16 기준이다.

## 카메라 화면 (확정, 구성 그대로)
- 3:4 원본 한 장을 찍는다. 9:16은 좌우만, 1:1은 위아래만 잘라 보여준다. 탭 순서 9:16 · 1:1 · 3:4, 기본 9:16. 용도 이름(스토리/피드) 쓰지 말고 비율 숫자만.
- 기록 글씨는 저장할 때 사진에 박는다. 비율마다 그 비율의 모서리에 붙는다. 9:16은 화면 가운데 3:4 틀이 있다고 치고 그 모서리에 붙인다. 그래서 9:16↔3:4를 바꿀 때 글씨는 한 픽셀도 안 움직인다.
  - 왼쪽 위: 날짜·운동명('11.10 MON · 등·이두'), 큰 '62분', '7,420kg · 18세트', 민트 띠 '지난번보다 4종목 상승'. 오른쪽 위: WATCHGYM. 오른쪽 아래: 종목 · 세트수 목록.
  - 크기·여백은 시안의 cqw 값(사진 틀 너비 기준 %)을 그대로 쓴다.
- 화면비를 바꾸면 사진 틀 높이, 사진 크기, 기록 글씨 위치가 **모두 같은 0.42초, 같은 곡선 cubic-bezier(.2,.8,.2,1)**로 함께 움직인다(글씨가 순간이동하면 안 됨). 탭 밑줄 점과 탭 줄 이동도 같은 시간·곡선.
- 글씨 색: 글씨 덩어리 셋(왼쪽 위, WATCHGYM, 오른쪽 아래 목록) **각각** 뒤의 사진 밝기를 재서, 밝으면 검정(#0B0B0A), 어두우면 흰색. 카메라 미리보기 밝기(Y 값)를 작게 줄여 1초에 몇 번 재면 충분하다. 깜빡임 방지 장치는 지금은 넣지 마라. 색 바뀜도 0.42초 같은 곡선. 그라데이션 덮개·블러 유리칸은 쓰지 마라.
- ✕: 왼쪽 위, 지름 37.4dp 동그라미, 배경 검정 45% + 뒤 블러 12dp, 흰 ✕ 아이콘 17.6dp(선 굵기 2, 끝 둥글게). 유리 효과·붉은 기·테두리 빛 없음.
- 하단: 비율 탭(사진 아래 끝에서 10dp), 그 아래 갤러리 썸네일 · 셔터 · 카메라 전환. 셔터를 누르면 번쩍이고(0.3초) 같은 자리가 '사진 저장'(민트) · '인스타 스토리' · '카카오톡' · '더보기'(안드로이드 기본 공유창)로 바뀐다. ✕ 자리에 '다시 찍기'. 찍은 뒤에도 비율을 바꿀 수 있다. 저장하면 '갤러리에 저장됨' 토스트.
- 저장·공유 이미지는 화면에 보이는 비율 그대로, 기록 글씨를 박은 상태로 만든다. 저장·공유는 `ResultImageExport.kt`를 재사용한다.
