# 운동 기록 탭 개편 — 앱 반영 지시서

디자인 정답 = `docs/handoff/records-tab-design.html` (브라우저로 열어서 두 화면을 본다: 왼쪽이 평소, 오른쪽이 꾹 눌러 선택 모드. 평소 화면 맨 위는 "운동 기록" 큰 제목 한 줄이고 오른쪽 위 + 버튼은 없다). 이 시안을 `RecordsScreen`(phone/.../ui/TabScreens.kt)과 `RecordCard`, 달력(`CalendarGrid`)에 Compose로 똑같이 옮긴다. 폰 프레임 바깥의 HTML 장식은 무시하고 안쪽 화면만.

## 색
앱의 `KColors`(Motion.kt)는 이미 새 중립 회색(C안)으로 바뀌어 있다. 시안의 변수는 이렇게 대응한다: --s1=Surface(#151617), --s2=SurfaceRaised(#212326), --s3=Selected(#2D2F33), --t1=Bone/White, --t2=Soft, --t3=Muted, --t4=Faint. 시안의 --day(달력 날짜 숫자)와 --accent2(숫자 보조 청록)처럼 KColors에 없는 값은 `tone-compare` 기준 C안 값(day #979BA0)을 이 화면 안에 상수로 둔다. 새 전역 토큰을 늘리지 말 것. 청록 = KColors.Accent, 진한 청록 면 = 시안의 --wash(#0E3A40)/--wash2(#0B2A2D), 빨강 = KColors.Red 계열.

## 화면 (위→아래)
1. 제목 "운동 기록" 한 줄. **오른쪽 위 + 버튼 제거** (TabPage의 오른쪽 아이콘 없음).
2. 달력 카드(Surface 면, 모서리 14dp): 월 이동 화살표(작은 둥근 네모 버튼), "2026년 **10월**"(연도는 작고 흐리게, 월은 크고 굵게), 요일, 날짜. **기록 있는 날 = 진한 청록 바탕의 둥근 네모(모서리 8dp) + 청록 숫자**(동그라미 아님), 오늘 = 아이보리 얇은 테두리. 좌우 스와이프로 월 이동은 기존 동작 유지.
3. "10월 기록 · 3회"(월은 달력에서 보는 달, 숫자는 그 달 기록 수).
4. 기록 카드 목록: 카드마다 Surface 면(모서리 14dp), 왼쪽 날짜 블록(48dp, 진한 청록 면, 청록 날짜 숫자 + 아래 요일), 가운데 운동 이름(굵게) + "N분 · N세트", 오른쪽 볼륨 "10,450" + 작고 흐린 "kg" + 그 아래 "볼륨", 점 세 개 메뉴. 숫자는 고정폭 숫자(tabular, 가능하면 FontFeature "tnum")로.
5. 하단 떠 있는 탭바는 이미 확정되어 코드에 있다. 건드리지 말 것.

## 선택 모드 (이미 코드에 있는 것을 시안대로 교체)
- 기록 카드를 꾹 누르면 켜진다(햅틱 있음). 맨 위 제목 줄이 선택 줄로 바뀐다: **왼쪽 동그라미 + 그 아래 "전체" 글자**(누르면 지금 보이는 달 기록 전부 선택, 전부 선택된 상태에서 다시 누르면 전부 해제. 동그라미는 비어 있다가 **전부 선택됐을 때만** 청록으로 차고 체크. 중간 상태 "–" 표시 없음), **가운데 "N개 선택됨"**(숫자만 청록), **오른쪽 "취소" 글자 + 빨간 단색 "삭제" 버튼**(휴지통 아이콘 + 글자, 선택 0개면 흐리게 눌리지 않음). 하단탭은 그대로 남는다.
- 카드 왼쪽에 선택 동그라미가 나타나고(점 세 개 메뉴는 숨김), 선택된 카드는 한 톤 밝은 면(Selected) + 청록 테두리 1.5dp(안쪽에 그려서 카드가 흔들리지 않게). 카드를 탭하면 토글. 평소와 선택 모드의 맨 위 높이를 같게 맞춰 모드가 바뀌어도 아래가 튀지 않게.
- 삭제 버튼은 기존 확인 팝업 → 삭제 흐름(`deleteRecords`)을 그대로 쓴다. 뒤로가기는 선택 모드를 푼다(기존).
- 이전에 넣은 "이 달 전체 선택/모든 기록 삭제" 칩과 네모 체크박스는 없애고 위 방식만 남긴다.

## 규칙
- 새 기능·새 문구 금지, 시안에 없는 건 만들지 않는다. 폰 폭 360~412dp에서 글자가 겹치거나 잘리지 않게.
- 코드 안의 기록 직접 추가용 + 버튼 제거로 진입점이 없어지는 기능이 있으면 지우지 말고 코드는 남겨 두고 보고서에 적는다.
- 커밋·push·배포 금지. 이 저장소(워치짐-앱수정)의 phone 모듈과 그 테스트만 고친다. 다른 작업의 미커밋 변경은 건드리지 않는다.
- 끝나면: `:phone:compileDebugKotlin :phone:compileDebugUnitTestKotlin` 통과, `RecordsAndResultMenuTest`(선택 모드 테스트는 새 UX에 맞게 고칠 것: "select-all" 태그 유지, 전체 선택→삭제 흐름), 그리고 선택 모드/평소 화면을 Roborazzi로 렌더해(`:phone:testDebugCompose -Proborazzi.test.record=true --tests ...`, 명령은 CLAUDE.md 참고) 시안과 눈으로 대조한다. 바뀐 것과 못 한 것을 `docs/handoff/2026-11-13-records-tab-report.md`에 짧게.
