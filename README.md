## 소개

워치짐은 헬스장에서 폰을 꺼내지 않고 운동하기 위한 앱이다. 워치를 찬 손목의 움직임으로 반복 횟수를 세고, 세트가 끝나면 휴식을 알려주고, 폰에는 그 기록을 쌓아 다음 세트와 다음 운동의 목표를 제안한다.
목표는 하나다. 운동하는 동안에는 시선을 기구에 두고, 기록과 계산은 앱이 알아서 하게 하는 것.

개인 사용을 위해 만든 앱이라 Galaxy Watch8과 Android 폰 한 쌍에 맞춰져 있다. 폰과 워치 앱은 서로 따로 설치되지만 같은 세션을 공유하고, 워치에서 끝낸 세트는 폰의 기록 달력에 그대로 들어간다.

## 주요 기능

**워치**
- 루틴 실행: 운동·세트·휴식 순서를 워치에서 그대로 따라간다.
- 자동 측정: 손목의 가속도계와 자이로스코프로 반복 횟수를 센다. 운동을 시작하면 손목이 잠시 가만히 있는 것을 확인한 뒤 측정이 시작된다.
- 휴식 타이머와 진동 안내: 세트가 끝나면 휴식으로 넘어가고, 끝날 때 진동으로 알려준다.
- 한 팔 운동 흐름: 찬 손의 세트가 끝나면 반대쪽 손 차례를 이어서 묻는다.
- 손목으로 세기 어려운 기구 운동은 수동 입력으로 안전하게 넘어간다.

**폰**
- 4분할 기본 루틴과 자유운동, 직접 만드는 루틴과 커스텀 운동.
- 운동 라이브러리: 부위별·도구별(맨몸, 덤벨, 바벨, 머신, 케이블)로 분류된 252개 운동. 비슷한 변형은 하나로 묶여 펼쳐 볼 수 있다.
- 3D 동작 미리보기: 운동마다 사람 모델이 기구를 쓰는 동작을 보여준다. 목록에서는 가벼운 움직이는 미리보기를, 상세 화면에서는 손가락으로 좌우 회전하는 3D를 쓴다.
- 기록 달력과 진행 화면: 날짜별로 한 운동과 세트 기록을 본다.
- 다음 목표 제안과 지난 세트 불러오기: 이전 기록을 바탕으로 점진적 과부하 목표를 제시한다.
- 앱 안 업데이트: 새 버전을 앱에서 바로 받는다.

## 운동 중 흐름

1. 폰에서 루틴을 고르거나 자유운동을 시작한다.
2. 워치에 첫 운동이 뜬다. 자세를 잡고 가만히 있으면 측정이 시작된다.
3. 반복하는 동안 워치가 횟수를 센다. 세트가 끝나면 무게와 횟수를 확인한다.
4. 휴식 타이머가 돌고, 끝나면 진동으로 알려준다.
5. 운동이 끝나면 세트 데이터가 폰으로 넘어가 기록에 저장된다.

## 모듈

- `core`: 루틴 진행, 휴식 판정, 인클라인 걷기 에너지 추정, 관측 가능한 손목 신호 분석, 점진적 과부하. Android 의존성이 없어서 기기 없이 단위 테스트한다.
- `wear`: Wear OS 루틴 실행기, 진동, Health Services 연동 지점, 센서 수집과 반복 측정 서비스.
- `phone`: 4분할 루틴, 자유운동, 운동 라이브러리, 3D·움직이는 미리보기, 기록 달력, 진행 화면, 앱 업데이트.
- `tools`: 릴리스 스크립트와 측정 데이터 점검 도구.
- `docs`: 제품 결정, 측정 흐름, 데이터 저장 설계, 운동별 측정 기준표 같은 설계 문서.
- `updates`: 앱 안 업데이트가 읽는 버전 안내 파일.

## 현재 단계

폰 0.2.x, 워치 0.2.x 개발 단계다. 스마트폰 앱에는 Obsidian 운동 기록을 기준으로 한 4개 기본 루틴과 실제 운동 라이브러리가 들어 있다. 운동별 3D 동작 모델과 움직이는 미리보기도 앱 안에 함께 들어 있다.
아직 검증하지 못한 부분도 분명히 적어둔다. 실제 워치 하드웨어 센서와 Health Services 심박수는 아직 검증하지 않았다. 일부 3D 동작은 로우폴리 모델의 한계로 완벽하지 않다.
`core`는 기기 없이 단위 테스트할 수 있도록 Android 의존성을 분리했다.

## 앱 업데이트

폰과 워치 앱은 GitHub Releases의 `update-phone.json`, `update-watch.json`을 읽어 앱 안에서 업데이트한다.
배포는 버전을 올리고 커밋한 뒤 `tools/release.sh "변경 내용"`을 실행한다. 폰만 올릴 때는 `--phone`, 둘 다 올릴 때는 `--both`를 붙인다. 스크립트는 작업 폴더가 깨끗해야 동작한다.
서명은 이 Mac의 `~/.android/debug.keystore`다. 이 키를 잃으면 기존 앱을 지우고 새로 깔아야 한다.

## 개발

Android 폰(minSdk 29)과 Wear OS 워치(minSdk 30)를 대상으로 하는 Kotlin 프로젝트이고 Gradle로 빌드한다.

```bash
gradle :core:test :phone:testDebugUnitTest :wear:testDebugUnitTest
```

3D 미리보기 자료는 용량이 커서 git에 올리지 않고, 빌드 전에 도구로 다시 만들어 앱 에셋 폴더에 넣는다. 설계 중인 3D 작업물은 `design/`에 있고 배포 저장소에는 올리지 않는다.

## 실기 검증

1. Watch8의 API 36 건강 권한과 Health Services 심박수 확인
2. 가속도계와 자이로스코프의 실제 sampling rate와 batching 확인
3. 화면 꺼짐과 연결 끊김 상태에서 세트 데이터 보존 확인
4. 덤벨 컬 자체 상태 머신과 실제 횟수 비교
5. 세트 종료 후 Data Layer Asset 전송과 ACK 확인
6. 폰에서 운동 목록을 빠르게 스크롤할 때 미리보기가 끊기거나 비지 않는지 확인
